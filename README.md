# Tutorial: Containerização com Docker e GitHub Actions

Este repositório é um guia prático para demonstrar como automatizar a compilação, teste e validação de aplicações web containerizadas com Docker utilizando pipelines de Integração Contínua (CI) no GitHub Actions.

## Objetivos do Projeto:
- Criar uma aplicação web servida por Nginx em contêiner Docker;
- Automatizar a verificação do contêiner via Pull Request com GitHub Actions;
- Aplicar boas práticas de controle de versão e fluxo de trabalho com Git.
